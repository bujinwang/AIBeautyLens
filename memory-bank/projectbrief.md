# Project Brief: AIBeautyLens

## 1. Project Mission

To develop a mobile application, AIBeautyLens, that provides users with AI-powered analysis of their skin, hair, or other beauty-related concerns, offering personalized advice and product recommendations.

## 2. Core Requirements

*   **AI-Powered Analysis:** Utilize AI models (currently Gemini, facing accessibility issues in China) to analyze user-submitted images or data.
*   **Personalized Feedback:** Provide users with tailored reports, insights, and recommendations.
*   **User-Friendly Interface:** Ensure an intuitive and accessible mobile application experience.
*   **Platform:** React Native with Expo for cross-platform (iOS/Android) development.
*   **Scalability:** Design the backend and cloud functions to handle a growing user base.
*   **Localization:** Support multiple languages, including for users in China.

## 3. Key Goals

*   Provide accurate and helpful beauty analysis.
*   Empower users to make informed decisions about their beauty routines and treatments.
*   Address the accessibility of AI services for all target user regions.

## 4. Scope

*   **Frontend:** Mobile application (React Native).
*   **Backend:** API services for user management, data storage, and orchestrating AI analysis.
*   **AI Integration:** Connect with AI models for analysis (currently Gemini).
*   **Cloud Infrastructure:** Utilize cloud functions for specific processing tasks.
